apology loop, the self-investigation, and the commit message that gives
it away.

## The entry

> My agent apologized 14 times for the same bug, then ran git blame and found the culprit: itself, at 3 a.m., commit message 'fixed it for real this time.'

## How it works

`main.py` writes that single line to `/output/entry.txt` and validates it
first: UTF-8 text, 1–200 characters, not only whitespace, exactly one
line, no control characters.

Run it:

```sh
python3 main.py
```
